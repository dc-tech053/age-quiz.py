**Purpose:**
This is a simple Python educational project that demonstrates the use of conditional logic (`if - elif - else` control structures) in a practical program.

**What it does:**
- Prompts the user to input their age
- Evaluates the input using conditional statements
- Outputs a message tailored to the age provided

**Use case:**
It's an introductory programming exercise designed to teach beginners how to:
- Handle user input
- Implement decision-making logic using conditional statements
- Create simple, interactive programs

This is a learning project, a beginner-friendly example of how to structure a program that makes decisions based on user data. It's a project from HyperionDev's software engineering boot-camp (2024); an introductory Python course.
